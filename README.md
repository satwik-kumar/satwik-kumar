### 🧠 VIBKED — Local AI Second Brain
`Python · FastAPI · React · ChromaDB · Mem0 · MCP`

> Built under hackathon pressure in 3 weeks. Didn't place. Shipped anyway.

A fully local, privacy-first AI second brain — no cloud, no subscriptions, nothing leaves the machine.

- **RAG pipeline** over personal notes + documents via ChromaDB vector search
- **Persistent memory** via Mem0 — the AI retains context across sessions without cloud storage
- **MCP tool calling** integration and **knowledge graph visualization** layer
- FastAPI backend + React frontend, structured like a real production codebase, not a tutorial project

What building this taught me: production-grade Python project structure, Git rebases and merge conflict resolution under a deadline, React component architecture on real async data flows.
